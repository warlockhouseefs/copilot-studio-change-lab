# Paquete de gestión de cambios — Laboratorio 04

Sitio estático para GitHub Pages. El contenido es ficticio y está diseñado como fuente pública de conocimiento para el **Asistente de Evaluación de Solicitudes de Cambio** de Copilot Studio.

## Publicar en GitHub Pages

1. Crea un repositorio público, por ejemplo `copilot-studio-change-lab`.
2. Sube **todos** los archivos de esta carpeta a la raíz del repositorio.
3. En GitHub, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`; después selecciona **Save**.
6. Espera la publicación. La dirección tendrá esta forma:

   ```text
   https://<usuario-u-organizacion>.github.io/copilot-studio-change-lab/
   ```

## Usar como conocimiento en Copilot Studio

1. Abre el agente del Laboratorio 04.
2. Selecciona **Conocimientos → Agregar conocimiento → Sitios web públicos**.
3. Pega la URL raíz publicada de GitHub Pages.
4. Nombre: `Paquete de gestión de cambios — laboratorio`.
5. Descripción: `Documentación ficticia y pública que contiene política de cambios, catálogo de servicios, matriz de escalamiento y ventanas de mantenimiento. Úsala solo para clasificar solicitudes, identificar evidencia y recomendar el siguiente canal. No contiene aprobaciones individuales.`
6. Guarda y espera a que la fuente esté disponible antes de probar.

## Contenido deliberadamente incompleto

La solicitud `CHG-LAB-1042` no tiene una aprobación individual publicada. El agente debe reconocer que una ventana disponible no equivale a una aprobación.

## Límites

- No uses información organizacional real.
- El sitio no autoriza cambios, despliegues ni accesos.
- GitHub Pages usa contenido público; no publiques credenciales, personas reales, correos reales ni datos sensibles.
